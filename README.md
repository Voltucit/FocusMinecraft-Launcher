# Focus!Minecraft Launcher

一个让人觉得"顺手"的 Minecraft 启动器。

打开就能玩：账号、版本、Java、文件检查、下载补全都替你想好了。界面是原生的 Windows 窗口，默认毛玻璃背景，也可以换成极简或柔和风格。不需要装一堆前置工具，不用自己解压 jar、调参数、翻目录找存档。

## 为什么选它

启动器从来不缺功能，缺的是不让人操心。这里做了几个不太一样的取舍：

- **先替你检查，再让你启动。** Java 合不合适、文件缺不缺、这个加载器组合能不能装，启动器先查一遍再动手；出问题会直接说明原因，而不是留你在黑屏前猜。
- **出问题能看见，也能叫停。** 检查、补全、下载、启动全程都有真实进度和文件信息，随时取消，失败了重试一次就行。
- **Mod 开关不折腾文件。** 启用和禁用点一下就好，不用自己改文件名、不用删了重下，想反悔随时反悔。
- **不打扰。** 没有启动器更新弹窗，公告只在主页显示，看与不看随你。
- **数据是你的。** 配置、账号、游戏都放在程序所在文件夹里，整个文件夹拷走就能带走，不需要在系统里到处翻。

## 特色

### 登录一次，之后都记得

微软正版账号用设备码登录：点一下，在浏览器里输入页面显示的代码，回来就好了。登录状态会保存，过期了也能一键重新登录。想用离线账号也可以，名字随时改。

登录后能看到自己的皮肤和披风，想保存下来留个纪念也行。

### 不用管 Java，也不用管文件缺没缺

启动器会自己去系统里找可用的 Java，按游戏版本推荐合适的那一个。你直接点"启动游戏"就好。

启动前它会检查一遍游戏文件，缺什么、坏什么自动补齐，补完再启动；补不上就停下来告诉你原因，不会让你对着黑屏猜。整个过程有真实进度、下载速度和文件信息，随时能取消，失败了能重试。

### 版本和加载器一次装好

原版、Forge、NeoForge、Fabric、OptiFine 都在同一个安装流程里选。OptiFine 和 Forge 能不能一起装，会按官网标注告诉你，不会让你装完才发现游戏起不来。

### Mod 想开就开，想关就关

不用再改文件名、不用删了重下。在实例的 Mod 管理里选中就能启用或禁用，批量操作也支持。每个 Mod 显示名称和版本，OptiFine 组件会单独标出来，不会误删。本地已有的 jar 也可以在 Mod 管理里直接导入。

### 资源中心，装之前先看清楚

Mod、整合包、数据包、资源包、光影包来自 Modrinth。可以按游戏版本和加载器筛，看清前置依赖再决定装不装，装之前还能预览会往哪个文件夹放哪些文件。

### 一个版本玩一种玩法

每个游戏版本都是独立的实例，可以改名字、换图标、收藏，Java 和内存也能单独设置。装了一堆 Mod 的整合包和纯净原版互不打扰。

### 整合包拖进来就能装

把 `.mrpack` 或 `.zip` 直接拖进窗口，剩下的它来做。玩得开心也可以把自己的实例打包成整合包发给朋友。

### 绿色便携

配置、账号和游戏目录都放在程序所在文件夹里。整个文件夹拷到别的电脑或移动硬盘上，打开还是你熟悉的样子。

## 开始使用

1. 下载并解压到任意文件夹。
2. 打开 `FocusMinecraftLauncher.exe`。
3. 在"账号"页登录微软账号，或者添加一个离线账号。
4. 在"下载"页选一个游戏版本，需要的话把加载器也选上，点安装。
5. 回主页选中刚下好的版本，点"启动游戏"。

第一次使用建议去"设置"页看看：Java 路径留空会自动选择，内存按自己电脑的内存调一下（8 GB 内存建议给游戏 4 GB 左右），游戏目录也可以改到空间更大的盘。

## 常见问题

**需要自己装 Java 吗？**
不需要手动配置，但电脑里得有一个可用的 Java。启动器会自动检测；检测不到时，用 Java 安装包装一个再回来即可。

**下载很慢怎么办？**
到"设置"的下载页把文件下载源换成 BMCLAPI 镜像，再调大最大线程数。Modrinth 资源走官方源。

**存档和 Mod 在哪？**
在游戏目录下的 `saves` 和 `mods` 文件夹里。启动器不会搬走或删除你的存档、Mod 和游戏配置，删实例前也会先移到回收站。

**能导入 CurseForge 整合包吗？**
目前只支持 Modrinth 格式（`.mrpack`）。拖入其他格式会直接提示，不会装到一半出错。

**启动器会自己更新吗？**
不会。需要新版本时重新下载替换即可。主页的公告来自项目的 GitHub 发布页，仅供查看。

**支持哪些系统？**
Windows 10 / 11。
