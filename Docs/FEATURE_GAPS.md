# 功能缺口与暂缓清单

日期：2026-10-24。当前 FMLauncher 依赖 FocusMinecraftCore 1.0.1。前一轮仅做外观；本轮所有者已追加授权安装自动同步、开发者配置分离和玩家界面整改。未授权的新增后端仍暂缓。下表不是已实现功能清单，也不表示所有缺口都属于 FMCore 缺陷。

## 已报告的核心问题与目录冲突

| 项目 | 已有证据与影响 | 本轮处理 |
| --- | --- | --- |
| 旧 Forge 与原版 ID 冲突 | agent.md 的 FMCORE-001：同名合并 JSON 与官方 SHA-1 不同，被 CacheOnly 拒绝 | 继续停止核心问题处理，不添加启动器兼容层 |
| Modrinth 图标、封面、图库 | agent.md 的 FMCORE-002：当前 SDK 项目模型未暴露图片字段；ResourceItem 也无图片字段 | 使用真实文字结果，不请求替代接口，不用统一图片冒充资源封面 |
| versions 工作目录下的 SDK 实例 / Mod / 整包写入 | 上一轮已核对 SDK 独立实例、Mod 安装器和整包写入 API 固定 instances；所有者仍要求 versions/<版本> | 不恢复冲突入口，不复制、链接或手改核心数据来规避 |

这些结论沿用上一轮源码和已安装 SDK 的核对记录；本轮没有修改或升级核心，也没有重新执行运行时验证。

## FMLauncher 尚未实现或未接入的部分

| 功能组 | 缺少的内容 | 与核心的关系 / 后续决定 |
| --- | --- | --- |
| 实例身份与来源 | 稳定 InstanceId、实例类别、来源平台、ProjectId / VersionId、清单哈希、来源与当前修改状态分离、版本演进及安全迁移 | 当前只有 VersionItem；需先确认与核心实例及 versions 目录的关联方案，不创建冲突的第二套身份系统 |
| 实例图标 | InstanceIconResolver、自定义覆盖、整包图标、加载器图标、与稳定 ID 关联的持久缓存及恢复默认 | 依赖身份和来源模型；本轮只用中性功能图形，不声称来源图标已完成 |
| 版本选择与管理 | 多游戏根目录列表、搜索分组、收藏、名称 / 描述 / 分类编辑、实例删除、存档与截图快捷目录、按实例独立设置 | 现有版本枚举、选中及目录命令保留；新业务先询问所有者 |
| 独立启动设置 | 全局与实例覆盖优先级、自动内存分配、内存可视化、窗口标题、自定义信息、启动前命令、离线皮肤 | 当前仍是原有全局设置，不添加无实际作用的开关 |
| Mod 本地管理 | 校验元数据后添加文件、批量冲突确认、启用 / 禁用 / 删除、版本设置页限定拖拽 | 现有页面只有搜索及打开 mods 目录；文件写入业务暂缓 |
| 在线社区资源 | 整包在线搜索与详情、发布版本选择、来源关联；数据包 / 资源包 / 光影包页面 | 当前 ResourceAdapter 只接 Mod 搜索；已有公开查询 API 不等于 FMLauncher 已完成集成，未接入部分不一概归因于核心 |
| 丰富资源信息 | 作者、标签、下载量、更新时间、兼容信息、真实资源图标与截图 | 当前展示模型仅有 ID、标题、简介、来源；Modrinth 图片字段缺口已确认，其他平台和字段需逐项核对 |
| 整合包流程 | 在线安装、本地导入安装、全窗口拖放、确认详情、安全冲突处理、来源持久化、图标保存、升级检查及导出 | 当前仅调用已有只读清单解析；写入先解决目录冲突，不通过 UI 模拟成功 |
| 下载目录与加载器详情 | 最新正式 / 快照推荐卡、分类展开收起、独立加载器详情卡、可用时的日期与稳定性字段 | 安装成功后的已安装状态标记本轮已接入；当前保留真实分类筛选与单一加载器选项，适配层只返回版本字符串，新增展示模型及数据接入先确认 |
| 完整任务系统 | 结构化任务 ID、等待队列、多个任务的独立进度与错误、重试、完成通知、独立速度 / 剩余文件 / ETA 字段 | OperationService 目前串行执行并保存文字记录；本轮任务页仅展示已有状态，不伪造多任务统计 |
| 主页及全局扩展 | 真实账号皮肤头像、自定义主页内容、启动器更新、下载策略、设置导入导出及新的缓存管理 | 当前只保留已存在功能；不把所有缺口归因于 SDK |

## 决策规则

出现新的后端问题或实际源码冲突时，先说明证据、影响范围并询问所有者，再记录决定。确认属于 FMCore 后停止该问题的代码处理，不在启动器中绕行。当前授权包含安装状态同步与配置分离，不授权实现上表其余暂缓业务。

## 本轮已确认并获准暂缓

- 离线账号改名：FMCORE-003，AccountManager 1.0.1 无公开改名接口。所有者明确暂缓并继续其他整改，不以删号重建代替改名。
- CurseForge 在线资源：所有者当前无 API 方案，明确先不提供。页面仅保留 Modrinth，展示未开放说明；这不是本轮确认的 FMCore 缺陷。
- Microsoft 公共应用 ID：所有者已提供并写入开发 / 发布嵌入配置；登录授权有效性待人工验证，不再要求普通玩家提供。
- 整包安装与实例图标 / 来源：本轮没有恢复冲突入口或新增来源模型，既有只读元数据和中性图标保留。整包成功通知的接线需待合法安装入口获准实现，不能称为本轮已修复运行流程。
