## 优先顺序和记录

先验证启动 / 导航、旧配置与版本工作目录，再验证离线账号、已安装 Java、本地原版及加载器启动。接着验证关闭策略、安装及修复、正版、外观和壁纸，最后测试资源查询。

每项记录程序构建、Windows / DPI、Java 主版本、游戏及加载器版本、实际版本目录、操作与结果、错误分类和日志路径。不要在截图或报告中包含设备码、Token、Key 或未检查的原始游戏日志。

SDK 独立实例、Mod 自动安装 / 更新、整包导入安装 / 更新 / 回滚 / 导出因最终目录要求而移除，不属于“等待运行通过”的功能，不能把它们标成已实现。
