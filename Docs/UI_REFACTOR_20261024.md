# 2026-10-24 外观与布局交付范围

## 所有者确认

本轮附件描述了全面 UI、实例和整合包升级。所有者进一步明确“优先执行更改外观任务”，并在能力冲突询问中选择：“先完成外观和现有功能布局，缺失后端暂缓”。因此本轮实施界面与导航，不实施附件中的新增后端系统，不绕过已报告的 FMCore 限制。

## 已实现的界面改动

- 主窗口以 1280 × 768 WPF 逻辑单位为基准，居中、可最小化及关闭，不提供最大化或拖动缩放。启动时按工作区收窄；原 PerMonitorV2 DPI 清单保留。
- 顶部“启动 / 下载 / 设置 / 更多”，左侧随分区切换，右侧为内容。分区保留最后访问页；内部快捷入口维护返回栈，Esc 可返回。
- 页面实例惰性创建并缓存，继续使用 LauncherServices 中原有 ViewModel，不因导航创建业务服务或取消任务。页面淡出、滑入采用透明度和位移变换，可被快速导航取消，并尊重主题及 Windows 动画开关。
- 主页固定左侧账号、版本和启动操作，右侧为旅程卡片、真实导航入口、维护和会话日志。账号使用中性头像图形，不伪造玩家皮肤或账号头像。
- 本地版本使用卡片列表；选择已保存版本后返回主页，仅同步已有展示对象。打开目录、mods、刷新、启动、校验、修复、停止及日志导出沿用现有命令。
- 下载页采用真实目录列表和安装选项两栏；原版、Fabric、Forge、NeoForge、OptiFine 保留。加载器区可折叠，只展示现有适配层提供的版本字符串，不编造日期或稳定性。
- 独立任务页展示现有 OperationService 的状态、阶段进度与最多 30 条结果记录；任务运行时右下角出现入口。未知总量不显示虚假的百分比。当前后端仍是串行任务服务。
- 账号页明确区分 Microsoft 与离线入口；Mod 页采用筛选栏、文字结果卡片及详情简介；整合包页保留清单读取。未增加无效的图片、安装或拖拽按钮。
- 启动设置按“Java 与内存 / 窗口与服务器 / 高级参数”分组。个性化按“主题与布局 / 壁纸与 API / 主题库与历史”分组，沿用原有预览、保存、导入导出及壁纸命令。
- 统一深浅色语义资源、间距、字体层级、导航选中与键盘焦点。保留用户主题色、壁纸、材质、透明度、圆角及动画设置。

## 设置草稿行为

启动设置和目录与服务使用同一份原有 Preferences 草稿。首次打开时读取保存配置，之后导航保留草稿。需要放弃草稿、同步 Java 页等入口已保存的新值时，点击“重新读取已保存设置”，确认后调用原有 RefreshDraft。保存仍通过原有 Save 命令；没有更改配置格式或持久化业务。
